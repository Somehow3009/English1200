🤖 Key Gemini của bạn ai học bằng quota của bạn

Đăng nhập rồi dán key miễn phí (lấy ở aistudio.google.com → Get API Key). Key được mã hóa AES-256 trên server, server chỉ giải mã trong RAM lúc chấm bài — không bao giờ hiện lại key, mỗi người học bằng quota API của chính mình.

Máy này còn key cũ lưu trên trình duyệt.
